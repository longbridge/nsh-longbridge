# Components

Find a component by what it is for; each name links to its spec. A change that adds or removes a public component
updates this table.

| Component | For (search terms) | Not for |
|---|---|---|
| [`AlertDialog`](alert-dialog.md), `AlertDialogContent`, `AlertDialogHeader`, `AlertDialogMedia`, `AlertDialogTitle`, `AlertDialogDescription`, `AlertDialogFooter`, `AlertDialogCancel`, `AlertDialogAction` | Alert dialogs, confirm dialogs, confirmations, "are you sure": a question that must be answered with a Cancel and an action | A form or a dismissable dialog (`Dialog`), the system's own alert (`nsh/base`'s `AlertDialog.show`), an undoable action (do it, then a `Toast` with Undo) |
| [`Avatar`](avatar.md), `AvatarBadge`, `AvatarGroup`, `AvatarGroupCount` | Avatars, profile pictures, initials, presence dots, avatar stacks with a "+3" count | Logos and thumbnails (`Image`), a status mark on its own (`Badge`), a pressable avatar (an avatar inside a ghost `Button`) |
| [`Badge`](badge.md) | Status marks, pills, categories, versions, counts | Pressable or removable tags (a `Button size="xs"`), shortcut keys (`Kbd`), a lone dot |
| [`Button`](button.md) | Buttons: primary, secondary, outline, ghost, destructive, link-styled, icon-only, loading | Opening a URL: use a link, not a `variant="link"` button |
| [`Calendar`](calendar.md) | Calendars, date grids, month views, day pickers, range calendars: a date or a range of dates picked on the page itself, several months side by side, disabled days | A date in a form field (`DatePicker`); several separate dates; events laid out on days (a scheduler) |
| [`Card`](card.md), `CardHeader`, `CardTitle`, `CardDescription`, `CardAction`, `CardContent`, `CardFooter` | Cards, panels, tiles, group boxes: a bordered surface with a title area, a body and a footer | A whole pressable card; notices (`Alert`, later); popups (`Popover`, `Dialog`) |
| [`Checkbox`](checkbox.md) | Checkboxes: accept terms, multiple selection, select all (indeterminate), a box alone in a table row | A setting that applies at once: `Switch`; one of a set: `RadioGroup`; a checkable menu item |
| [`Combobox`](combobox.md) | Comboboxes, autocomplete pickers, searchable selects, tag pickers: one value or several (as chips) from a long list the user types to filter (a framework, a country, labels) | A short fixed set (`Select`, `RadioGroup`); free text with suggestions; commands (`DropdownMenu`) |
| [`DataTable`](data-table.md) | Data tables, data grids, spreadsheet-like lists: thousands of rows or columns, sorting, resizing, moving and fixed columns, a keyboard cursor, a checkbox column | A few rows of mixed content the app lays out (`Table`), items of different shapes (a list) |
| [`DatePicker`](date-picker.md) | Date pickers, date fields, date range pickers, date and time pickers: a field that opens a calendar (a sheet on touch screens), presets, a time row; with `confirm`, Cancel / Apply, typed start and end fields and presets showing their dates | The days always on the page (`Calendar`); typing a date as text (an `Input`); the system's own wheel (`nsh/mobile`'s `DateTimePicker`) |
| [`Dialog`](dialog.md), `DialogContent`, `DialogHeader`, `DialogTitle`, `DialogDescription`, `DialogFooter`, `DialogClose` | Dialogs, modal windows, modals: a form or a message in a centered panel over a dimmed page, which keeps the focus until it closes | A question that must be answered (`AlertDialog`), a panel next to its button (`Popover`), a bottom sheet (`nsh/base`'s `Sheet`), a passing notice (`Toast`) |
| [`DropdownMenu`](dropdown-menu.md), `DropdownMenuItem`, `DropdownMenuCheckboxItem`, `DropdownMenuRadioGroup`, `DropdownMenuRadioItem`, `DropdownMenuLabel`, `DropdownMenuSeparator`, `DropdownMenuShortcut`, `DropdownMenuGroup`, `DropdownMenuSub`, `DropdownMenuSubTrigger` | Dropdown menus, action menus, overflow (⋯) menus, account menus: commands and settings a button opens; checkable and radio items, shortcuts, submenus | Choosing a value a form submits (`Select`); a right-click menu (ContextMenu, later); a window's menu bar |
| [`Field`](field.md), `FieldLabel`, `FieldDescription`, `FieldError`, `FieldContent`, `FieldTitle`, `FieldGroup`, `FieldSet`, `FieldLegend`, `FieldSeparator` | Form fields, form rows, settings rows, fieldsets: a control with its label, help text and validation error; vertical, horizontal or responsive; choice cards | Validation and form state (the app's own code); a label alone (`Label`) |
| [`Input`](input.md) | Single-line text fields: name, email, password, search term, filter; sizes, invalid, read-only, disabled | Several lines (`Textarea`), numbers with steps (`nsh/base`'s `NumberInput`), a choice from a list (`Select`) |
| [`Kbd`](kbd.md), `KbdGroup` | Keyboard shortcuts, hotkeys, key hints, in menus, buttons and tooltips | Status marks (`Badge`), monospaced code |
| [`Label`](label.md) | A form field's name; pressing it focuses the field (`htmlFor`) | The words beside a Checkbox, Switch or RadioGroup item (their children); descriptions and errors (`Field`) |
| [`Pagination`](pagination.md) | Pagination, pagers, page numbers: Previous, the pages around the current one, Next; a compact "3 of 12" | Scrolling through every row (`DataTable` needs no pages), steps of a flow, tabs |
| [`Popover`](popover.md), `PopoverHeader`, `PopoverTitle`, `PopoverDescription` | Popovers, popup panels, flyouts: a small form or a few settings next to the button that opened it, closed by a press outside | Hints (`Tooltip`), lists of actions or options (`DropdownMenu`, `Select`), what must be answered first (`Dialog`) |
| [`Progress`](progress.md) | Progress bars: uploads, downloads, steps done, storage used; an indeterminate bar for unknown length | Activity of unknown length in a small place (`Spinner`), a value the user sets (`Slider`) |
| [`RadioGroup`](radio-group.md), `RadioGroupItem` | Radio buttons: one of a small set, all visible (a plan, a sort order), in a column or a row | Many options: `Select`; switching views: `Tabs`; a segmented control (`ToggleGroup`) |
| [`Select`](select.md) | Selects, drop-down lists, pickers, pop-up buttons: one value from a fixed set (a country, a time zone, a sort order), in groups; thousands of options | Two to five options all worth seeing (`RadioGroup`); searching or typing a value (`Combobox`); commands (`DropdownMenu`) |
| [`Separator`](separator.md) | Dividers, rules, `hr`: between sections (horizontal) or the items of a row (vertical) | Menus and toolbars (`nsh/base`'s `MenuSeparator`, `ToolbarSeparator`); a block's own edge (`border-b`) |
| [`Skeleton`](skeleton.md) | Loading placeholders in the shape of the content to come | Unknown shapes or quick loads (`Spinner`, or nothing) |
| [`Slider`](slider.md) | Sliders, range sliders: a number from a range picked by dragging (volume, brightness, a price range with two thumbs), horizontal or vertical; a histogram of the results above the track (price filters), marks and tick labels below it, a value bubble (value tooltip) above the thumb | An exact number typed or stepped (`nsh/base`'s `NumberInput`), progress the user does not change (`Progress`), a chart of its own (a histogram that is not a filter) |
| [`Spinner`](spinner.md) | Loading or activity indicators of unknown length | A button's own wait (`Button`'s `loading`), known progress (a progress bar) |
| [`Switch`](switch.md) | Switches, toggles: a setting on or off that takes effect at once (notifications, dark mode) | An option applied on submit or a required item: `Checkbox`; a toolbar toggle button (`Toggle`) |
| [`Table`](table.md), `TableHeader`, `TableBody`, `TableFooter`, `TableRow`, `TableHead`, `TableCell`, `TableCaption` | Tables, simple tables, invoice tables: rows the app writes, with a header, totals, a caption, selected rows and controls in cells | Thousands of rows, sorting or resizing columns (`DataTable`), laying out a form in columns |
| [`Tabs`](tabs.md), `TabsList`, `TabsTrigger`, `TabsContent` | Tabs, tab bars, segmented views: switching between views of one page, one shown at a time; underlined (`line`) or segmented; horizontal or vertical | Choosing a value a form submits (`RadioGroup`, `Select`); navigating between pages or routes |
| [`Textarea`](textarea.md) | Multi-line text fields: notes, descriptions, feedback, a message draft; grows with its text | One line (`Input`), rich text or code (`nsh/base`'s editors) |
| [`Toaster`](toast.md), `toast()`, `dismissToast()` | Toasts, snackbars, flash messages, notifications in the window: saved, copied, failed with "Retry", deleted with "Undo"; a loading toast replaced by its result | What must be answered (`AlertDialog`), a field's error, a lasting state of the page, system notifications outside the window |
| [`Toggle`](toggle.md) | Toggle buttons: a format or view option that stays on or off (bold, show grid), an icon or words | A setting applied at once (`Switch`); one of several options (`ToggleGroup`) |
| [`ToggleGroup`](toggle-group.md), `ToggleGroupItem` | Toggle groups, segmented controls, button groups: one value or several from a few options shown as toggles (alignment, view mode, text styles) | Switching views of a page (`Tabs`); a form's choice with labels (`RadioGroup`) |
| [`Tooltip`](tooltip.md) | Hints, hover hints: an icon button's name, a truncated label's full text, a shortcut | What the user must see (it hardly shows on touch screens), pressable content (`Popover`) |
